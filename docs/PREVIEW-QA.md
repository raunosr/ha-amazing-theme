# Esikatselun selaintarkistus

Version 0.2.0 hehku, kahdeksan palettinäytettä, dialogi ja asettelu tarkistettiin 8.9.2026 uudelleen kaikilla alla olevilla leveyksillä. Työpöytä-, mobiili- ja dialogikuvat päivitettiin ja katsottiin läpi.

Paikallinen esikatselu tarkistettiin headless Microsoft Edgellä (Chromium), Playwrightin avulla.

- Leveydet 1440, 1024, 736, 390 ja 320 px: ei sivun tai korttien vaakaylivuotoa.
- Dialogi mahtuu joka leveyteen ja sulkeutuu Escape-näppäimellä.
- Version 0.1.0 toiminnallisessa kokeessa molemmat kytkimet, kirkkaussäädin, tila-/virhe-esimerkit ja dialogin kuittaus toimivat.
- Ei JavaScript-virheitä eikä ulkoisia verkkopyyntöjä.
- Kuvakaappaukset: työpöytä, puhelin ja dialogi.

Tämä testaa vain mukana toimitettua havainnollistusta. Aidon HA-käyttöliittymän tarkistukset on lueteltu tiedostossa COMPATIBILITY.md.
